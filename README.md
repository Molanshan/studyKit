# 题Kit

离线优先的复习刷题工具。导入 docx / txt / pdf 复习题，自动识别题型，反复刷题、自动收录错题，题库与作答数据只保存在本机。

## 功能

- 导入 docx / txt / md / pdf（文本型），也支持直接粘贴题目文本
- 自动识别单选、多选、判断、填空、简答、名词解释
- 填空题逐空判分，可关闭逐空给分
- 题库按题型筛选；题集以标签形式展示，一道题可属于多个题集
- 题库区分浏览 / 编辑模式：浏览时只看题，编辑时才可改题、建题集、导入
- 练习模式：边答边看 / 答完再判，答题卡、自动下一题、续刷
- 结果页逐题回顾，错题本支持标记掌握、重练
- JSON 备份导出 / 合并导入 / 覆盖恢复
- 移动端底部导航，PC 端侧边栏，深色模式与主题色

## 导入模板

识别率最高的写法：

```text
一、单项选择题
1. 题干（ ）
A. 选项一
B. 选项二
C. 选项三
D. 选项四
答案：B
解析：可选

二、填空题
2. ____ 和 ____ 是两个空
答案：第一空|第二空

三、判断题
3. 这句话是正确的。（ ）
答案：对
```

- 题号支持 `1.`、`1、`、`1)` 等常见形式
- 答案支持 `答案：`、`参考答案：`、`【答案】`
- 填空题多个空用 `|`、`；`、`①` 或编号分隔
- 未识别片段不会静默丢弃，会在导入预览中列出
- 开发环境可访问 `/#/debug/parser` 查看解析细节与置信度

## 数据

- 题库、题集、错题、练习记录：Dexie / IndexedDB（数据库名 `tikit`）
- 偏好设置：`localStorage`（键名 `tikit-settings`）
- 清理浏览器站点数据会删除题库，请定期在「我的 → 导出备份」保存 JSON
